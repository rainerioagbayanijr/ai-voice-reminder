# TTS integration, privacy, and deployment boundaries

Reviewed on 15 October 2026. This is an engineering assessment for the fictional MVP; production use requires the institution's legal, privacy, security, and collections-policy approval.

## Which Edge TTS integration is used?

[edge-tts.com](https://edge-tts.com/) presents a browser conversion interface. Its public pages reviewed here do not document a supported developer API or publish a Python package maintained by the site. We do not scrape it or depend on its internal browser endpoints, and no affiliation between that site and the Python package is assumed.

The implementation installs the separately maintained [rany2/edge-tts Python package](https://github.com/rany2/edge-tts), pinned to 7.3.1. Its `edge_tts.Communicate(...).stream()` API accesses Microsoft's online speech service used by Edge. It requires outbound network access; no Edge browser, local speech engine, paid API key or GPU is installed. Docker self-hosts the adapter and workflow, not Microsoft's voices. The package is a third-party client, not an official Microsoft enterprise speech API contract.

Rate and volume use the package's supported percentage parameters. Arbitrary SSML is unsupported by the package/service; ordinary punctuation provides pauses. The adapter uses bounded concurrency, output size, connect/receive timeouts and a total deadline. No offline fallback is shipped, and provider behavior/availability may change.

The service's live voice list was queried during implementation. It returned `en-PH-JamesNeural`, `en-PH-RosaNeural`, `fil-PH-AngeloNeural`, and `fil-PH-BlessicaNeural`. Both Filipino voices were confirmed again on 16 October 2026. Availability can change: run `edge-tts --list-voices` before adopting them. English and Filipino sample templates ship. To use Filipino, review `fil/voice.txt`, `fil/subject.txt`, `fil/email.txt`, select `LANGUAGE=fil`, set both `VOICE` and `ALLOWED_VOICES`, and rebuild. Filipino dates use Filipino month names. Taglish has no guaranteed dedicated locale; pronunciation, wording and tone need human review. Sample templates are not a claim of institutional or legal approval.

## Terms and commercial suitability

The site's [terms](https://edge-tts.com/terms/) say generated output can be used commercially, but also make the underlying Microsoft technology subject to its own terms and disclaim service warranties. That statement is not a Microsoft grant covering our separate Python client's automated financial-services use. The site's [privacy policy](https://edge-tts.com/privacy/) likewise does not establish retention or contractual assurances for direct requests made by this package.

Review the installed package's [license](https://github.com/rany2/edge-tts/blob/master/LICENSE), [Microsoft Services Agreement](https://www.microsoft.com/en-us/servicesagreement), and [Microsoft Privacy Statement](https://www.microsoft.com/en-us/privacy/privacystatement). The installed 7.3.1 license identifies LGPLv3 for the library, with MIT applying only to its SRT composer file; preserve notices and review distribution obligations. A software license does not by itself grant rights to the online service, voices, or customer-data processing. The general terms include restrictions on unauthorized access and bypassing protections; we do not infer enterprise authorization, guaranteed usage limits, data residency, retention, a processor agreement, or an SLA from a working technical request. No verified official commercial API contract for this access method was established. Therefore commercial financial-services suitability remains unapproved; use this client only for the fictional prototype until those rights and controls are confirmed. A future provider adapter can be substituted if a contracted service is required; none is added to this MVP.

## Data flow and minimization

Speech text includes first name, institution, agent and due date. Those values are sent to Microsoft over the package's remote connection; the system cannot honestly claim all customer data stays self-hosted. Customer email, phone, balances, card/account numbers and tracking IDs are not included in speech. The reference website is not in this data path. Do not infer the provider's retention behavior from this application's in-memory cleanup.

Email is plain text with one MP3 attachment. All destinations are overridden to a controlled test inbox; verifying ownership is an explicit operator responsibility enforced by a startup configuration gate. The prototype has no production-recipient mode. SMTP providers and inboxes may retain email and audio. n8n retains operational metadata and transient binary files; execution payload saving is disabled. Dry-run previews intentionally persist on disk for listening and must be removed under an appropriate retention policy. Files, database references, backups and access logs require access control even when they omit balances.

## Philippine deployment considerations

- The [Data Privacy Act of 2012 (RA 10173)](https://privacy.gov.ph/data-privacy-act/) requires an appropriate lawful basis, transparency, proportionality, security and respect for data-subject rights. Determine controller/processor responsibilities, notices, lawful processing grounds, retention, access controls, breach procedures and applicable registration requirements. A generic consent checkbox does not resolve every processing purpose.
- [NPC Circular 2020-01 as amended by 2022-02](https://privacy.gov.ph/npc-amends-circular-on-the-processing-of-personal-data-for-loan-related-transactions/) addresses loan-related processing. Its amendments restrict unnecessary/excessive processing and distinguish character references from guarantors; reference contact details are not permission to collect from unrelated people. Apply data minimization and purpose limits to outsourced messaging and cross-border speech processing too.
- [SEC MC No. 18, series of 2019](https://www.sec.gov.ph/mc-2019/mc-no-18-s-2019/) governs unfair debt-collection practices for covered financing/lending companies and third-party providers. Obtain review of tone, timing, frequency, identity disclosure, confidentiality and complaint handling. Do not harass, threaten, shame, misrepresent legal consequences or disclose debts to unauthorized third parties.
- For BSP-supervised institutions, assess the applicable [BSP financial consumer protection framework, including Circular 1160](https://www.bsp.gov.ph/Pages/InclusiveFinance/FinancialConsumerProtectionNetwork.aspx), alongside credit-card/collection-specific rules and institutional outsourcing requirements. Applicability differs by regulated entity; the MVP is not a compliance certification.

Before real customer use, implement authoritative consent/lawful-basis checks, opt-out and suppression lists, verified destination ownership, current account/payment status, channel preferences, recipient-local contact hours, frequency caps, complaints handling, approved templates, privacy/security assessment of the speech and email providers, and an audit/retention policy. These policy checks belong before claiming and should be rechecked before delivery where policy can change. This MVP deliberately implements only fictional CSV eligibility plus the mandatory test recipient override.
